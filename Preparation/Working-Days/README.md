# Working Days

Counts working days between dates and adds working days to dates, skipping weekends and UK or US public holidays, with SLA checks.

Working-day arithmetic that knows about **public holidays**, not just weekends:

- **Count** the working days between a start and an end date (for example raised and resolved)
- **Add** N working days to a date to get a **due date** (N from a field, such as an SLA per priority, or a fixed number)
- With both, an **SLA check**: *Met Target* yes / no and *Working Days Late*

Public holidays are generated by rule, for any year, for **England and Wales**, **Scotland**, **Northern Ireland** (bank holidays, with substitute days and the one-off UK holidays since 2011 such as jubilees, the coronation and the state funeral) or the **US** (federal holidays, observed dates). Add your own closure dates (office shutdowns, company days) and choose the weekend (Saturday and Sunday, Friday and Saturday, Sunday only, or none).

The second output lists every holiday used, so the calendar can be checked or reused.

Omniscope's NETWORKDAYS formula counts weekdays only; this block adds holidays, due dates and SLA checks.

## Language
Python

## Inputs
- **Input 1**: records with a start date and optionally an end date and / or a number of working days.

## Options

| Group | Option | Name in script | Type | Description |
|---|---|---|---|---|
| Dates | Start date | `start_field` | Field | For example the date a ticket was raised or an order placed. From input 1. |
| Dates | End date (to count working days) | `end_field` | Field | For example the date it was resolved or delivered. From input 1. |
| Dates | Working days to add (field) | `days_field` | Field | A number of working days per row, such as the SLA for its priority. From input 1. |
| Dates | Working days to add (fixed) | `days_constant` | Whole number | Used when no field is chosen. 0 = do not add. Default: 0. |
| Dates | Count the start day | `include_start` | Tick box | Ticked: Monday to Friday of the same week is 5 working days. Unticked: 4. Default: ticked. |
| Calendar | Public holidays | `region` | Choice | Public holidays that are not working days. Choices: England and Wales; Scotland; Northern Ireland; United States (federal); None (weekends only). Default: England and Wales. |
| Calendar | Extra closure dates | `custom_holidays` | Text | Comma-separated dates, such as 2025-12-29, 2025-12-30, 2025-12-31. |
| Calendar | Weekend | `weekend` | Choice | Days that are not working days. Choices: Saturday and Sunday; Friday and Saturday; Sunday only; No weekend. Default: Saturday and Sunday. |
| Calendar | Text dates are day first | `day_first` | Tick box | Read 03/04/2025 as 3 April. Default: ticked. |

## Outputs
- **Working days** (`result`): The input with Start Is Working Day, Working Days, Calendar Days, Due Date, Met Target and Working Days Late as applicable.
- **Holiday calendar** (`holidays`): Every holiday used: date, name, region, weekday.
